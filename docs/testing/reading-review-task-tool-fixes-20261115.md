## 修复范围

- 保存任务标准输出、标准错误和结构化错误（阶段、调用栈、退出状态）；浏览器命令另存完整日志，优先提取 CLI 标准输出中的真实错误，不再只显示 npm 警告。界面提供“日志”，安全地按纯文本显示末尾 24,000 字符。
- 批量任务的实翻／识别依赖本次采集成功，并绑定该次产出的快照 ID。采集失败则后续已跳过，不读取历史快照兜底。运行前核验 HTML／资源和验证页；已知受限采集不自动反复重试。
- 区分原文覆盖、译文插入、同语种／空内容跳过、不支持、等待、处理中、失败。终态稳定后结束观测；没有处理中任务且 30 秒无进展记为 `no-progress`，另保留总时限。跳过和不支持不增加覆盖，不作为合格实翻基线。
- 不完整实翻的目标、逐项状态、设置、停止原因和译文仍落盘，运行保留 `incomplete`；任务显示“受限结束”。遮罩阻挡按钮时显示“已跳过”并保留具体拦截元素。
- 当前任务优先显示、排队按先后排序，并显示最后进展时间。

诊断适配器仅调用锁定源码的纯语言检测函数，结合实际配置记录执行条件，不改目标收集函数。首轮新增适配器因误引入 WXT 存储初始化发生 `storage is not defined`，日志已保留；随后移除该依赖，并补上真实采集器在无 storage 环境下执行的回归测试，才进行下表正式重跑。首轮失败没有被覆盖或计为成功。
