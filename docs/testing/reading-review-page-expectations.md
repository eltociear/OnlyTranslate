# 只标问题后保存整页期望

本次按用户确认的新流程调整评审工具，未提交。识别算法、已有真实人工标注和已接受限制均保留。

## 行为

- 正确部分无需逐项操作。只标问题，点击“完成本页评审”时先保存本页草稿，再合成整页期望。
- 未标注部分沿用本次识别结果；“该翻”补全对应块，“不该翻”排除对应块，“都可以／待定”保持不约束。待定不会被当作正确答案。
- 有待修复问题也能保存评审。评审进度与算法校验状态分别显示，可以同时为“评审已完成”和“有 3 处待修复”。
- 构建仍重新回放快照检查保存的期望。不符合期望就阻断；算法达到期望后无需重做人工评审。用户明确判断新的结果更合理时，可更新期望并保留历史。
- 已接受限制仍按原始精确绑定判断，只允许对应差异非阻断；没有改原裁决，也没有把已接受问题算作修复。
- 新格式记录 schemaVersion 2 保存观察覆盖、合成期望和不约束位置，各自有完整性校验。旧版本 1 保持精确覆盖原意，不自动迁移或重写。
